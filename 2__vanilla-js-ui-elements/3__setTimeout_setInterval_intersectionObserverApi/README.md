# setInterval(), localstorage, IntersectionObserverApi

> **❗ Attention:** Components from the `Example` folder project called pseudo-components because using that realization of components isn't being used on real projects; that's uncofortable in usage and hard to develop on bigger projects. This showed here only as an example.

## Task

1) Look at the project in the `Example` folder. There's an example of a home page with intersectionObserver call on block with a `.faq` class border crossing on 30% (.3 of the block size) and a modal with a timeout before the user will be allowed to click the "Close" button. There's localstorage item setting for storing the value (do this modal show earlier).
2) Make similar home page with annoying modal window. Use intersectionObserver and localstorage for serving purposes like in the example.
